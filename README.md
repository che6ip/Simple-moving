# Simple moving

Простое перемещение токенов по клику для **Foundry VTT v14**.

Выберите токены на сцене и кликните в видимую им область — модуль построит маршрут с линией
пути, маркером конечной точки, подсветкой клетки и дистанцией. Второй клик по этой же точке
перемещает токены штатной анимацией Foundry. Работает с любой игровой системой.

## Возможности

- Предпросмотр маршрута с учётом стен, препятствий и тумана войны.
- Маркер назначения с пульсирующим кольцом и «уголками» целевой клетки.
- Подсветка клетки приземления и подпись дистанции с пометкой «недостижимо».
- Промежуточные пункты маршрута по **Ctrl + ЛКМ**.
- Отмена плана по **ПКМ** или **Esc**.
- Настраиваемый цвет маршрута, показ дистанции, подсветка клетки и радиус подтверждения.
- Опциональная активация только при зажатом **Alt** — обычные клики остаются нетронутыми.
- Русская и английская локализация.

## Установка

1. Скопируйте папку `simple-moving` в каталог модулей Foundry: `Data/modules/simple-moving`.
2. Включите модуль в настройках мира (**Manage Modules**).
3. Обновите сцену клавишей **F5**.

Зависимостей нет.

## Как пользоваться

1. На слое **Токены** выберите один или несколько токенов инструментом «Выбор».
2. **Кликните по свободной клетке**, видимой токену, — появится маршрут.
3. **Кликните ещё раз по конечной точке** — токены переместятся туда.
4. Клик в другом месте перестраивает маршрут на новую точку.

| Действие | Результат |
| --- | --- |
| **ЛКМ по свободной клетке** | Построить или перестроить маршрут |
| **ЛКМ по конечной точке** | Переместить токены |
| **Ctrl + ЛКМ** | Добавить промежуточный пункт |
| **ПКМ** или **Esc** | Отменить план |
| **ЛКМ по другому токену** | Снять предпросмотр и выделить этот токен |
| **Alt** (в режиме «только с Alt») | Разрешить перехват клика |

Если маршрут упирается в стену, препятствие или туман войны, точка помечается красным крестом и
подписью «недостижимо» — модуль предложит выбрать другую клетку. Перетаскивание токена или
движение с клавиатуры автоматически снимает предпросмотр.

## Настройки

Настройки находятся в разделе настроек модуля и хранятся отдельно для каждого игрока.

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Перемещение по клику | включено | Главный переключатель режима |
| Активация режима | всегда | Можно требовать удержания **Alt** |
| Цвет маршрута | ваш цвет игрока | Палитра образцов и системный color-picker; выбор применяется сразу |
| Показывать дистанцию | включено | Подпись расстояния у конечной точки |
| Подсвечивать клетку назначения | включено | Заливка целевой клетки цветом маршрута |
| Радиус подтверждения | 0.75 клетки | Насколько близко нужно кликнуть к маркеру для перемещения |

## Совместимость

- Foundry VTT **14** (проверено на сборке 14.369).
- Система не важна — модуль системно-независимый.
- Поддерживаются токены разных размеров и сети square/hex/gridless.
