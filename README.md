# Simple moving

Простое перемещение токенов по клику для **Foundry VTT v14** (проверено на сборке 14.369).
Система не важна — модуль системно-независимый.

Модуль превращает обычный клик по сцене в планировщик движения: выберите токены на слое
**Токены**, кликните в видимую им область — появится маршрут с линией пути, маркером конечной
точки, подсветкой клетки и дистанцией. Второй клик по этой же точке перемещает токены штатной
анимацией Foundry.

## Возможности

- предпросмотр маршрута, построенного самим Foundry с учётом стен, препятствий и тумана войны;
- маркер назначения с пульсирующим кольцом и «уголками» целевой клетки;
- подсветка клетки приземления и подпись дистанции (с пометкой «недостижимо»);
- промежуточные пункты маршрута по **Ctrl + ЛКМ** (цепочка точек);
- отмена плана по **ПКМ** или **Esc**;
- настройки внешнего вида: цвет маршрута (палитра), показ дистанции, подсветка клетки,
  радиус подтверждения;
- опциональная активация только при зажатом **Alt**, чтобы обычные клики оставались нетронутыми;
- локализация: русский и английский.

## Установка

1. Скопируйте папку `simple-moving` в каталог модулей Foundry:
   `Data/modules/simple-moving` (рядом должен лежать `module.json`).
2. Запустите Foundry и включите модуль в настройках мира (**Manage Modules**).
3. Перезагрузите мир или обновите сцену (**F5**). Модуль не требует зависимостей и не
   устанавливает свои CSS-файлы — стили окна выбора цвета внедряются скриптом.

## Как пользоваться

1. Включите модуль в настройках мира и обновите сцену.
2. На слое **Токены** выберите один или несколько токенов (инструмент «Выбор»).
3. **ЛКМ по свободной клетке**, видимой токену, — модуль построит и покажет маршрут:
   - линия пути (с учётом стен и тумана войны), бегущие точки вдоль маршрута;
   - маркер конечной точки с пульсирующим кольцом и «уголками» клетки назначения;
   - подсветку клетки, куда попадёт токен, и подпись дистанции.
4. **Второй ЛКМ по этой же конечной точке** — токены перемещаются туда (штатная анимация Foundry).
5. Клик в другом месте — маршрут перестраивается на новую точку.

### Управление

| Действие | Результат |
| --- | --- |
| **ЛКМ по свободной клетке** | Построить или перестроить маршрут для выбранных токенов |
| **ЛКМ по конечной точке** | Переместить токены по показанному маршруту |
| **Ctrl + ЛКМ** | Добавить промежуточный пункт к маршруту |
| **ПКМ** или **Esc** | Отменить план, ничего не перемещая |
| **ЛКМ по другому токену** | Снять предпросмотр и выделить этот токен (маршрут не «переезжает» к чужой фишке) |
| **Alt** (в режиме «только с Alt») | Разрешить перехват клика |

Дополнительно:

- **ЛКМ по другому токену**, когда предпросмотр уже показан, снимает маршрут и выделяет этот
  токен: путь не «переезжает» к чужой фишке. То же работает с Ctrl+выделением. Если токен стоит
  ровно на размеченной клетке назначения, клик по нему так же подтверждает перемещение;
- перетаскивание токена, движение с клавиатуры или любое другое перемещение автоматически снимает
  предпросмотр;
- если маршрут упирается в стену/препятствие/туман войны, точка показывается красным крестом и
  подпись «недостижимо» — подтверждение в этом случае не перемещает токен, а подсказывает выбрать
  другую клетку.

## Настройки

Настройки находятся в разделе настроек модуля и хранятся только для клиента (у каждого игрока
свой набор). Переключатели сделаны выпадающими списками, цвет выбирается из палитры, радиус
подтверждения — штатное числовое поле Foundry с ползунком.

| Настройка | Как выбирать | По умолчанию | Описание |
| --- | --- | --- | --- |
| Перемещение по клику | список | включено | Главный переключатель режима |
| Активация режима | список | всегда | Вариант «только с зажатым Alt» оставляет обычные клики нетронутыми |
| Цвет маршрута | палитра | ваш цвет игрока | Кнопка «Выбрать цвет» открывает окно с образцами: сначала идёт ваш игровой цвет, далее 18 оттенков и системный color-picker для точного оттенка. Выбор сохраняется сразу, предпросмотр перерисовывается мгновенно |
| Показывать дистанцию | список (показывать / не показывать) | включено | Подпись расстояния у конечной точки |
| Подсвечивать клетку назначения | список (подсвечивать / не подсвечивать) | включено | Заливка целевой клетки через штатный API подсветки сетки |
| Радиус подтверждения | число с ползунком (0.25–3) | 0.75 клетки | Насколько близко нужно кликнуть к маркеру, чтобы переместить токен |

Важно про цвет: значение по умолчанию из цвета игрока действует для новых установок и для
кнопки «Взять мой цвет». Если цвет уже был сохранён предыдущей версией модуля, он не сбрасывается —
образец вашего игрового цвета стоит в палитре первым, и переключение занимает один клик.

## Технические детали

- Режим работает на слое **Токены** при выбранном инструменте «Выбор». Пока выбран инструмент
  «Измерение» (линейка) или активен уже начатый замер, модуль клики не перехватывает; инструменты
  создания объектов (фишки, стены, области и т. п.) также не затрагиваются.
- Маршрут строит сам Foundry: `Token#findMovementPath(...)` с `preview: true`, поэтому он
  корректно обрезается стенами и туманом войны так же, как при перетаскивании токена.
  Измерение — через `Token#measureMovementPath`.
- Перемещение выполняется документированным API v14: `TokenDocument#move(waypoints, {...})` с
  учётом истории движения ядра; предпросмотр маршрута линейкой ядра при этом не рисуется
  (`showRuler: false`).
- Точка клика привязывается к сетке через `canvas.grid.getSnappedPoint`, позиция токена
  вычисляется через `TokenDocument#getSnappedPosition`/`getCenterPoint` — корректно для токенов
  размером больше одной клетки и для шестиугольных сетей.
- Оверлей рисуется собственным контейнером на слое токенов (`eventMode: "none"`), использует
  штатную подсветку клеток сетки, `PIXI.Graphics` (smooth) и `PreciseText`; анимация — через
  общий тикер сцены.
- План автоматически сбрасывается, если изменился набор выбранных токенов, позиция токена, слой
  или сцена; Esc/ПКМ отменяют его вручную.
- Клик по объекту токена и клик по свободной клетке различаются: для объекта предпросмотр
  вызывается с флагом `onToken`, поэтому сначала проверяется близость к размеченной точке
  назначения, а во всех остальных случаях предпросмотр снимается и выделение обрабатывает ядро.
- Настройки регистрируются через `foundry.data.fields` (`StringField` с `choices`, `ColorField`,
  `NumberField`), поэтому в интерфейсе отображаются списки, палитра и ползунок. При запуске
  выполняется миграция значений, сохранённых ранними версиями.

## Совместимость

- Foundry VTT **14** (проверено на 14.369). Система не важна.
- Токены разных размеров и сети square/hex/gridless поддержаны в части построения маршрута;
  для gridless используется позиция без привязки к клеткам.
- Модуль не патчит ядро навсегда: подменяются только классы слоя токенов и токена через
  `CONFIG.Canvas.layers.tokens` и `CONFIG.Token.objectClass`, а вся логика вызывается из
  переопределённых обработчиков кликов.

## Версии

### 0.1.2

- Исправлено оформление настроек: раньше модуль регистрировал поля неверным ключом, и Foundry
  показывал текстовые поля вместо списков. Теперь `enabled`, «Показывать дистанцию»,
  «Подсвечивать клетку назначения» и «Активация режима» — выпадающие списки, радиус подтверждения —
  числовое поле с диапазоном 0.25–3.
- Цвет маршрута больше не текстовое поле: в настройках появилась кнопка «Выбрать цвет», открывающая
  палитру образцов (первым — ваш цвет игрока) плюс системный color-picker; выбор применяется сразу
  и перекрашивает уже нарисованный маршрут.
- Значение по умолчанию для цвета теперь берётся из цвета текущего игрока (`game.user.color`), а не
  фиксированного оранжевого.
- Исправлено преобразование цвета: v14 отдаёт настройки цвета объектом `foundry.utils.Color`, и
  раньше выбранный в палитре оттенок мог доезжать до маршрута как цвет по умолчанию. Теперь значение
  приводится к HEX-строке через `Color.from` во всех местах (настройки, предпросмотр окна, линия
  пути, точки, подсветка клетки).
- Добавлена миграция значений, сохранённых предыдущими версиями (старые строки/булевы значения
  приводятся к новому формату).
- Клик по чужому токену при активном предпросмотре больше не продлевает маршрут до него:
  предпросмотр снимается, а ядро выполняет обычное выделение. Клик по токену, который стоит на
  размеченной клетке назначения, как и раньше перемещает фишку (проверка точки выполняется первой).
